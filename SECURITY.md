# Security Policy

## Reporting a Vulnerability

Open a [GitHub Security Advisory](https://github.com/przemekhys/homeassistant-operator/security/advisories/new) — do not use public issues for security reports.

Dependency vulnerabilities are the most likely risk and are tracked automatically via [govulncheck](.github/workflows/security.yml) and [Dependabot](.github/dependabot.yml).
